# JID — Wave Delivery Master Plan

**Authority date:** 2026-08-26
**Active doctrine:** [`WAVE_OPERATING_MODEL.md`](WAVE_OPERATING_MODEL.md)

The previous Codex-only, fixed-phase, 90-day operating plan is superseded. Historical
commits and reports remain evidence, but they do not schedule current work.

## Delivery rule

Each capability moves through:

`Research/Reuse Gate -> Architecture -> Build -> Validate -> Review -> Close -> Next Wave`

Every substantial subsystem receives an explicit reuse decision before implementation.
Each wave closes before dependent foundations are mutated. Research may start early when
it does not create competing contracts or implementation.

This is dependency order, not a calendar. A wave may be divided into smaller packets after
repository inspection.

## Agent pipeline

- Claude Code owns research, architecture, algorithms, methodology, and OSS diligence.
- Codex owns canonical backend/data/security integration, tests, and technical closeout.
- Cursor owns Arabic-first product experience and frontend execution.
- ChatGPT / Nebras owns strategy, orchestration, synthesis, and verification.

GitHub carries every handoff by branch, SHA, exact files/contracts, test evidence, risks,
and next entry point.

## Permanent controls

- Hybrid Rebuild: preserve trustworthy foundations; replace unsupported product structure.
- No production write or deployment without explicit founder approval.
- No feature, metric, AI claim, institutional outcome, or verification without evidence.
- AI is assistive, explainable, and human-authorized.
- Privacy is enforced before data reaches unauthorized clients.
- The final compact Trust & Rights Constitution remains a founder governance follow-up;
  no agent may invent adoption.
