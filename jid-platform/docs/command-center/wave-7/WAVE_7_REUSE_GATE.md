# Wave 7 reuse gate

Decision: `BUILD` the orchestration delta on the existing Wave 5/6 contracts; `BUY-PARTNER` specialized assessment delivery and recorded-video infrastructure after provider approval.

Reused: applications, hiring roles/criteria/stages/team authority, Wave 6 observations/evidence attachments, immutable audit log, Supabase RLS/RPC pattern, Next.js API/i18n/design foundations. No external library is needed for the provider-neutral state machine. External coding, psychometric, proctoring, and video systems remain vendor integrations; Wave 7 stores only governed provider/session/recording references. This avoids importing an online-test platform or biometric inference stack.

Rejected: greenfield test engine, proprietary psychometric scoring, universal candidate score, generic invasive proctoring, facial/voice/emotion/personality inference, and provider-specific schema coupling.
